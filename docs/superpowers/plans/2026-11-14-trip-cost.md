# Trip Cost Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show an approximate running cost for every trip and trip group (fuel at the local average price + time-based and wear-based shares of the other running costs).

**Architecture:** A new Core class `TripCosts` builds per-day totals once per `AnalysisContext` (lazy), with prefix sums, so each trip's 91-day fuel window and 365-day pool window cost O(1). The Web layer wraps `Trip`/`TripGroup` in view records that add `cost`. The React trip list and drawer show it.

**Tech Stack:** C# / .NET 10, xUnit, ASP.NET Core minimal APIs; React 19 + TanStack Query + vitest/testing-library.

**Spec:** `docs/superpowers/specs/2026-11-14-trip-cost-design.md` (read it first; it is binding).

## Review Focus

1. A foreign-currency expense without a home amount must be skipped, not counted as 0-currency-mismatch money (Task 1 test).
2. No fuel price anywhere (a vehicle with trips but no fuel expenses) → `Fuel` and `PricePerLitre` null, `Total` = time + wear, no exception (Task 1 test).
3. A trip with zero duration or zero km must not divide by zero; a window's rate is 0 when the window has no hours/km (Task 1 test).
4. Expenses dated (or covering days) outside the trips' date range — e.g. coverage starting a year before the first trip — must not index out of the per-day arrays (Task 1 test).
5. The trip GET of another vehicle/user's trip still returns 404 after switching it to an analysis session (Task 2 test).

### Task 1: Core `TripCosts`

**Interfaces:**
- Produces:
  - `public sealed record TripCost(decimal? Fuel, decimal Time, decimal Wear, decimal Total, decimal? PricePerLitre, string Currency);` (in `TripCosts.cs`, namespace `DriverBalance.Core`; values rounded with `Money.Round`)
  - `public sealed class TripCosts { public static TripCosts Build(VehicleData data); public TripCost Of(Trip trip); public TripCost Of(TripGroup group); }`
  - `AnalysisContext.Costs` → `TripCosts` (built on first use, then cached).
- Group rule: `Fuel` = sum of the trips' unrounded fuel (null if any trip's fuel is null), `Time`/`Wear`/`Total` = sums, `PricePerLitre` = null. Round after summing.

Approach: one day index from the earliest to the latest day touched by any trip start date, any expense date or any coverage day (only non-Purchase expenses with a home amount). Per-day `double` arrays (cumulative/prefix form): time-pool cost, wear-pool cost, fuel spend (all fuel expenses, pro rata), fuel spend and litres of fuel expenses with `Litres > 0` (both pro rata by coverage), trip km, trip hours, trip litres (by `DateOnly.FromDateTime(trip.Start)`). Spread a coverage-period expense as amount/days per covered day (use a difference array to stay linear). Window sums clip to the index range. Fuel price for a window: litres-bearing spend ÷ litres if litres > 0; else fuel spend ÷ trip litres if both > 0; else the same rule over the whole range; else null. Trip formula from the spec:
`time = h × T/H; wear = 0.5 × km × W/K + 0.5 × h × W/H; fuel = litres × price` (a rate with a 0 denominator is 0).
